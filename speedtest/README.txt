================================================================================
Speedtest Benchmark Utility for R36H (playOS / ARM64)
================================================================================

เครื่องมือทดสอบความเร็วอินเทอร์เน็ต (Speedtest Benchmark) สำหรับเครื่องเล่นเกม R36H
รันบนระบบปฏิบัติการ playOS ออกแบบมาเพื่อวัดค่า:
  1. ค่าความหน่วง (Ping / Latency) ในหน่วย ms
  2. ความเร็วดาวน์โหลด (Download Speed) ในหน่วย Mbps
  3. ความเร็วอัปโหลด (Upload Speed) ในหน่วย Mbps
  4. ข้อมูลเครือข่าย: ISP, IP Address, และพิกัดเซิร์ฟเวอร์ทดสอบ

--------------------------------------------------------------------------------
จุดเด่นของเครื่องมือ (Features)
--------------------------------------------------------------------------------
1. Dual-Output Display:
   - แสดงผลแบบสรุปสวยงามทั้งบนหน้าจอเครื่อง R36H (/dev/tty1) และหน้าจอ Terminal / SSH
2. Standalone & Pre-patched:
   - บรรจุโมดูล speedtest.py ไว้ภายใน ไม่ต้องดาวน์โหลดใหม่ทุกรอบ
   - แก้ไขปัญหา Cloudflare 403 Forbidden และ Python 3.13 deprecation warning ให้พร้อมใช้งาน
3. Handheld Friendly UX:
   - ตรวจสอบสถานะการเชื่อมต่อ Wi-Fi ก่อนเริ่ม (Pre-flight check) แจ้งเตือนชัดเจนหากยังไม่ต่อเน็ต
   - ระบบตรวจจับปุ่ม Gamepad (/dev/input/event*) และปุ่มบนคีย์บอร์ด พร้อมนับถอยหลัง 15 วินาที
     ก่อนกลับสู่หน้าเมนู EmulationStation อัตโนมัติ (หน้าจอไม่เด้งหายทันที)
4. Memory Optimized:
   - ปิดโหมด Pre-allocation ขณะทดสอบอัปโหลด ประหยัดแรม 1GB ของ Rockchip RK3326

--------------------------------------------------------------------------------
โครงสร้างไฟล์ (Directory Structure)
--------------------------------------------------------------------------------
speedtest/
├── Install_Speedtest.sh    <-- สคริปต์ติดตั้งระบบเข้าสู่ /roms/tools/ และ /usr/local/bin/
├── speedtest.sh            <-- ตัวเรียกใช้งานหลักสำหรับเมนู EmulationStation
├── speedtest_runner.py     <-- สคริปต์ประมวลผลและจัดหน้าจอแสดงผลภาษาไทย
├── speedtest.py            <-- โมดูล Speedtest CLI ฉบับ Offline Patched
└── README.txt              <-- เอกสารแนะนำการใช้งาน

--------------------------------------------------------------------------------
วิธีการติดตั้ง (Installation)
--------------------------------------------------------------------------------
วิธีที่ 1: ติดตั้งผ่านหน้าจอเครื่อง R36H
  1. คัดลอกโฟลเดอร์ speedtest ไปวางไว้ที่ /roms/tools/speedtest/
  2. เปิดเครื่อง R36H เข้าเมนู Tools
  3. เลือกและสั่งรัน "Install_Speedtest.sh"

วิธีที่ 2: ติดตั้งผ่าน Terminal Emulator หรือ SSH
  รันคำสั่ง:
    sudo bash /roms/tools/speedtest/Install_Speedtest.sh

--------------------------------------------------------------------------------
วิธีการใช้งาน (Usage)
--------------------------------------------------------------------------------
วิธีที่ 1: ใช้งานผ่านหน้าจอเครื่องเล่นเกม
  - เข้าเมนู Tools บน EmulationStation
  - เลือกรายการ "Speedtest"
  - ระบบจะตรวจสอบเน็ต วัด Ping, Download, Upload แล้วสรุปผลบนหน้าจอ
  - กดปุ่มใดก็ได้บนเครื่อง หรือรอ 15 วินาที เพื่อกลับสู่เมนูเกม

วิธีที่ 2: ใช้งานผ่าน Terminal / SSH
  - พิมพ์คำสั่ง:
      speedtest
  - หรือสั่งรันตรง:
      sudo bash /roms/tools/speedtest/speedtest.sh
