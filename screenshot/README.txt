==============================================================================
Screenshot Suite & Hotkey Daemon for R36H (playOS / ARM64)
==============================================================================

ชุดเครื่องมือจับภาพหน้าจอ (Screen Capture) ประสิทธิภาพสูง ออกแบบเฉพาะสำหรับ
เครื่องเล่นเกมพกพา R36H (Rockchip RK3326) บนระบบปฏิบัติการ playOS

คุณสมบัติเด่น (Features):
------------------------------------------------------------------------------
1. คีย์ลัดระดับระบบ (Global Hotkey: SELECT + Y):
   - ทำงานเป็น Background Daemon ผ่าน systemd service
   - สามารถกด [SELECT + Y] เพื่อจับภาพหน้าจอได้ตลอดเวลา
   - ใช้งานได้ทั้งในหน้าเมนู EmulationStation และขณะกำลังเล่นเกม (RetroArch,
     PPSSPP, DraStic ฯลฯ)
   - ไม่ต้องสลับเข้าเมนู Tools หรือออกจากเกมที่กำลังเล่น

2. เอฟเฟกต์ชัตเตอร์กล้อง (Camera Flash Effect):
   - มีการกะพริบแสงหน้าจอชั่วขณะ (~80ms) หลังจากเซฟภาพสำเร็จ
   - ยืนยันการจับภาพทันทีโดยไม่กวนสายตาหรือหน่วงเฟรมเรตของเกม

3. ป้องกันการกดซ้ำ (Debounce & Cooldown):
   - มีระบบหน่วงเวลา 1.2 วินาที ป้องกันการบันทึกภาพซ้ำซ้อนหากเผลอกดแช่

4. การจับภาพผ่าน Linux Framebuffer (/dev/fb0):
   - ดึงภาพตรงจากชิปประมวลผลด้วย ffmpeg
   - ความละเอียดคมชัดเต็มจอ 640x480 พิกเซล รูปแบบไฟล์ PNG คุณภาพสูง
   - บันทึกไฟล์ที่ /roms/screenshots/screenshot_YYYYMMDD_HHMMSS.png
   - ตั้งสิทธิ์ไฟล์เป็น ark:ark อัตโนมัติ เปิดดูหรือดาวน์โหลดผ่าน Web File Manager ได้ทันที

5. คำสั่ง CLI สำหรับ SSH และ Terminal:
   - สั่งแคปภาพจากคอมพิวเตอร์ผ่าน SSH หรือพิมพ์คำสั่งบนเครื่องได้โดยตรง
   - รองรับการตั้งเวลานับถอยหลัง เช่น 'screenshot 3'

6. ตัวตรวจสถานะและโหมดทดสอบปุ่ม (Button Tester):
   - มีสคริปต์ Status_Screenshot.sh สำหรับตรวจเช็คสถานะ Process, RAM และรูปภาพล่าสุด
   - มีโหมดทดสอบปุ่มกดแบบ Realtime เพื่อตรวจสอบปุ่มบนเครื่องและรหัส Event


โครงสร้างไฟล์ในชุดเครื่องมือ:
------------------------------------------------------------------------------
d:\me\r36h\tools\screenshot\
├── Install_Screenshot.sh       <-- สคริปต์ติดตั้ง Daemon และคำสั่ง CLI
├── Status_Screenshot.sh        <-- สคริปต์ตรวจเช็คสถานะ + โหมดทดสอบปุ่มกด
├── Uninstall_Screenshot.sh     <-- สคริปต์ถอนการติดตั้งอย่างสมบูรณ์
├── README.txt                  <-- เอกสารคู่มือการใช้งานฉบับนี้
├── app/                        <-- โฟลเดอร์แอพพลิเคชันภายใน
│   └── screenshot.sh           <-- สคริปต์จับภาพหน้าจอสำหรับ CLI (/usr/local/bin/)
└── daemon/                     <-- โฟลเดอร์ Daemon และ Service
    ├── screenshot_daemon.py    <-- Python Daemon ตรวจจับปุ่ม SELECT + Y
    └── screenshot-daemon.service <-- Systemd service unit


วิธีติดตั้ง (Installation):
------------------------------------------------------------------------------
รันคำสั่งติดตั้งผ่าน Terminal หรือ SSH:
   sudo bash /roms/tools/screenshot/Install_Screenshot.sh

สคริปต์จะทำการ:
1. ติดตั้งคำสั่ง 'screenshot' ลงใน /usr/local/bin/
2. ลงทะเบียนและเปิดใช้งาน systemd service (screenshot-daemon.service)
3. เริ่มทำงาน Background Daemon อัตโนมัติ
4. ลบทางลัดเมนูเดิมใน /roms/tools/ (หากมี) เพื่อให้ไม่เกะกะหน้าเมนู Tools


วิธีใช้งาน (Usage):
------------------------------------------------------------------------------
1. ใช้งานผ่านปุ่มลัด (Hotkey):
   - ขณะเปิดเครื่อง อยู่ที่หน้าเมนู หรือกำลังเล่นเกมใดๆ:
     กดปุ่ม [SELECT] ค้างไว้แล้วกด [Y] พร้อมกัน
   - หน้าจอจะกะพริบคล้ายชัตเตอร์กล้อง 1 ครั้งเมื่อภาพถูกบันทึกสำเร็จ

2. ใช้งานผ่าน Terminal / SSH:
   - บันทึกภาพทันที:
       screenshot
   - บันทึกภาพพร้อมนับถอยหลัง (เช่น 3 วินาที):
       screenshot 3
   - สั่งแคปจากคอมพิวเตอร์ผ่าน SSH:
       ssh ark@<IP_เครื่อง> "sudo screenshot"

3. ตรวจสอบสถานะและทดสอบปุ่ม (Status & Diagnostics):
   - รันคำสั่ง:
       sudo bash /roms/tools/screenshot/Status_Screenshot.sh
   - จะแสดงสถานะ Service, PID, RAM, จำนวนภาพที่เซฟไว้ และบันทึกล่าสุด
   - กด [T] หรือ [1] เพื่อเข้าสู่ Button Test Mode สำหรับกดดูปุ่มบน Gamepad แบบสดๆ

4. ดาวน์โหลดภาพออกจากเครื่อง:
   - ผ่าน Web File Manager: เข้าพอร์ต 80 (เช่น http://192.168.1.9) แล้วเปิดโฟลเดอร์ /roms/screenshots/
   - ผ่าน SFTP/SCP: ดึงไฟล์จากไดเรกทอรี /roms/screenshots/


วิธีถอนการติดตั้ง (Uninstallation):
------------------------------------------------------------------------------
หากต้องการปิดการทำงานและถอนการติดตั้ง:
   sudo bash /roms/tools/screenshot/Uninstall_Screenshot.sh

หมายเหตุ: ไฟล์ภาพทั้งหมดใน /roms/screenshots/ จะยังคงถูกเก็บรักษาไว้ ไม่ถูกลบ
