==============================================================================
Screenshot Utility for R36H (playOS / ARM64)
==============================================================================

เครื่องมือบันทึกภาพหน้าจอ (Screen Capture) ออกแบบเฉพาะสำหรับเครื่องเกม R36H
รองรับการจับภาพผ่าน Framebuffer (/dev/fb0) โดยตรง ทำให้สามารถแคปได้ทุกหน้าจอ
ทั้งเมนูระบบ EmulationStation และขณะกำลังเล่นเกม

คุณสมบัติหลัก (Features):
- ดึงภาพผ่าน Linux Framebuffer (/dev/fb0) โดยตรงด้วย ffmpeg
- ความละเอียดมาตรฐาน 640x480 พิกเซล รูปแบบไฟล์ PNG คุณภาพสูง
- รองรับระบบ Dual-Execution (เรียกจากเมนู Tools หรือ Terminal/SSH)
- กำหนดเวลานับถอยหลัง (Timer Countdown) เพื่อให้มีเวลาสลับหน้าจอก่อนบันทึกภาพ
- บันทึกไฟล์อัตโนมัติลงใน /roms/screenshots/ พร้อมตั้งชื่อตามวันเวลา (Timestamp)

โครงสร้างไฟล์ในชุดเครื่องมือ:
------------------------------------------------------------------------------
- screenshot.sh          : สคริปต์หลักสำหรับจับภาพหน้าจอ
- Install_Screenshot.sh  : สคริปต์ติดตั้งเข้าสู่เมนู Tools และระบบ CLI
- README.txt             : คำแนะนำการใช้งานฉบับนี้

วิธีติดตั้ง (Installation):
------------------------------------------------------------------------------
1. คัดลอกโฟลเดอร์ screenshot ไปไว้ในเครื่อง R36H (เช่น /roms/tools/screenshot)
2. รันคำสั่งติดตั้งผ่าน Terminal / SSH:
     sudo bash /roms/tools/screenshot/Install_Screenshot.sh

วิธีใช้งาน (Usage):
------------------------------------------------------------------------------
1. ใช้งานผ่านเมนูหน้าเครื่อง (EmulationStation):
   - ไปที่เมนู Tools -> Screenshot
   - หน้าจอจะเริ่มนับถอยหลัง 3 วินาที แล้วทำการบันทึกภาพ
   - เมื่อบันทึกเสร็จ จะแสดงที่อยู่ไฟล์ภาพและกลับสู่เมนูอัตโนมัติ

2. ใช้งานผ่าน Terminal หรือ SSH:
   - บันทึกภาพทันที:
       screenshot
   - บันทึกภาพแบบนับถอยหลัง (เช่น นับ 5 วินาที):
       screenshot 5

3. แคปหน้าจอจากคอมพิวเตอร์ผ่าน SSH ส่งภาพกลับมาเซฟบนคอมฯ ทันที:
   - บน PowerShell หรือ Terminal ของ PC:
       ssh ark@<IP_เครื่อง> "sudo screenshot"
       หรือดึงไฟล์ภาพจาก /roms/screenshots/ ผ่าน File Manager/SFTP
