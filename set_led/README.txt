================================================================================
LED Color Switcher Utility for R36H (playOS)
สคริปต์สลับสีไฟสถานะ LED (สีแดง / สีน้ำเงิน) สำหรับ R36H
================================================================================

1. ภาพรวม (Overview)
--------------------------------------------------------------------------------
สคริปต์ชุดนี้พัฒนาขึ้นมาเพื่อแก้ปัญหาไฟสถานะ (Power Indicator LED) สีน้ำเงินของเครื่อง
R36H ที่สว่างจ้าแยงตาเวลาเล่นเกมในที่มืด โดยให้ผู้ใช้สามารถสลับระหว่าง "สีแดง" (Red)
และ "สีน้ำเงิน" (Blue) ได้ทันทีจากเมนู TOOLS บนหน้าจอ EmulationStation (playfe)

จุดเด่น:
- สลับสีไฟได้ทันทีแบบเงียบๆ (Instant Switch) ไม่มีหน้าต่างค้างรบกวน
- โฟลเดอร์ติดตั้ง "set_led" ถูกซ่อนจากหน้าเมนู TOOLS อัตโนมัติ (Stem-Matching Rule)
  โดย playfe จะเห็นชื่อ "setled" ตรงกับ "setledtored" และ "setledtoblue" ด้านนอก
- จำค่าสีที่เลือกไว้ถาวรข้ามการรีบูต (Boot Persistence)
- ทำงานร่วมกับระบบเตือนแบตเตอรี่ (batt_led.service) อย่างสมบูรณ์แบบ

2. โครงสร้างไฟล์ (File Structure)
--------------------------------------------------------------------------------
set_led/
├── Install_Set_LED.sh         <-- สคริปต์ติดตั้ง (คัดลอกเมนูไปยัง /roms/tools/)
├── Uninstall_Set_LED.sh       <-- สคริปต์ถอนการติดตั้งและคืนค่าไฟเริ่มต้น
├── README.txt                 <-- คู่มือการใช้งาน
└── app/
    ├── Set_LED_to_Red.sh      <-- สลับเป็นไฟสีแดงทันที (gpio77 = 1)
    └── Set_LED_to_Blue.sh     <-- สลับเป็นไฟสีน้ำเงินทันที (gpio77 = 0)

3. วิธีติดตั้ง (Installation)
--------------------------------------------------------------------------------
วิธีที่ 1: ติดตั้งผ่านเมนู TOOLS บนเครื่อง R36H
1. คัดลอกโฟลเดอร์ set_led ไปไว้ที่ /roms/tools/set_led
2. รันสคริปต์ Install_Set_LED.sh

วิธีที่ 2: ติดตั้งผ่าน SSH (Terminal)
$ sudo bash /roms/tools/set_led/Install_Set_LED.sh

เมื่อติดตั้งเสร็จแล้ว จะมีเมนูใหม่ปรากฏขึ้นในหมวด TOOLS ของ playfe / EmulationStation:
- [ Set_LED_to_Red.sh ]  : กดเพื่อเปลี่ยนเป็นไฟสีแดง
- [ Set_LED_to_Blue.sh ] : กดเพื่อเปลี่ยนเป็นไฟสีน้ำเงิน

4. ข้อมูลทางเทคนิคเกี่ยวกับฮาร์ดแวร์ R36H (Technical Notes)
--------------------------------------------------------------------------------
- หลอดไฟของเครื่อง R36H เป็นแบบ Bi-Color LED (น้ำเงิน/แดง) ควบคุมผ่านขา GPIO 77
- gpio77 = 0 : ไฟสีน้ำเงิน (ค่าเริ่มต้นเดิม)
- gpio77 = 1 : ไฟสีแดง (แสงนุ่มนวล สบายตากว่าในที่มืด)
- ฮาร์ดแวร์ไม่มีวงจรตัดไฟแยก จึงไม่สามารถสั่งดับไฟสนิท 100% ผ่าน Software ได้
  (หากต้องการมืดสนิท ต้องติดเทปดำทับหลอดไฟด้านในตัวเครื่อง)
- ดูรายละเอียดเชิงลึกฉบับเต็มได้ที่ LED_HARDWARE_GUIDE.md ในโฟลเดอร์หลักของโปรเจกต์
