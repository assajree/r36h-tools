================================================================================
  Universal Setup UI Engine (setup_ui) สำหรับ R36H (playOS)
================================================================================

1. ภาพรวม (Overview)
--------------------------------------------------------------------------------
`setup_ui` คือโปรแกรม UI ตัวกลาง (เขียนด้วยภาษา C + Direct SDL2 KMSDRM)
ที่ช่วยให้สคริปต์ `.sh` ทุกตัวบนเครื่อง R36H สามารถสร้างหน้าจอเมนูติดตั้งแบบกราฟิก
(640x480 @ 60FPS) ได้ทันทีโดยไม่ต้องแก้โค้ด C หรือคอมไพล์ใหม่ เพียงแค่ส่งข้อความ
ตั้งค่า (INI-style block) เข้าไปทาง `stdin`

ทำงานได้ทั้งการเปิดจาก:
  - เมนู EmulationStation (Tools)
  - แอป playOS Terminal (FindManager)
  - SSH จากคอมพิวเตอร์

--------------------------------------------------------------------------------
2. โครงสร้างไฟล์ในโฟลเดอร์ setup_ui/
--------------------------------------------------------------------------------
  - setup_ui          : ไบนารี ARM64 สำเร็จรูป (พร้อมก๊อปปี้ไปใช้ในโปรเจกต์อื่นทันที)
  - setup_ui.c        : ซอร์สโค้ดภาษา C ฉบับเต็ม (เผื่อต้องการแก้ไขหรือคอมไพล์ใหม่)
  - Demo_Setup.sh     : สคริปต์แม่แบบตัวอย่าง (Template) สำหรับนำไปดัดแปลง
  - README.txt        : คู่มือการใช้งานและการเขียนคำสั่งตั้งค่า

--------------------------------------------------------------------------------
3. การควบคุมด้วยปุ่มบนเครื่อง R36H
--------------------------------------------------------------------------------
  - D-Pad ขึ้น / ลง (หรืออนาล็อกซ้าย) : เลื่อนเลือกตัวเลือก [X] Option 1..N
  - D-Pad ซ้าย / ขวา               : เลื่อนเลือกปุ่มคำสั่งด้านล่าง [ OK ] / [ Back ] / [ Exit ]
  - ปุ่ม A หรือ ปุ่ม B               : กดสั่งทำงานปุ่มด้านล่างที่กำลังไฮไลท์อยู่
      * ไฮไลท์ที่ [ OK ]   + กด A/B = ยืนยัน Option ที่เลือก แล้วไปหน้าถัดไป
      * ไฮไลท์ที่ [ Back ] + กด A/B = ย้อนกลับไปหน้าก่อนหน้า (หน้าแรกปุ่ม Back จะปิดไว้)
      * ไฮไลท์ที่ [ Exit ] + กด A/B = ออกจากโปรแกรมทันทีโดยไม่ทำการเปลี่ยนแปลง

--------------------------------------------------------------------------------
4. วิธีนำไปใช้ในโปรเจกต์อื่น (ไม่ต้องคอมไพล์ใหม่)
--------------------------------------------------------------------------------
1) ก๊อปปี้ไฟล์ไบนารี `setup_ui` ไปไว้ในโฟลเดอร์ย่อยของเครื่องมือนั้นๆ
   เช่น `my_tool/daemon/setup_ui` หรือ `my_tool/app/setup_ui`
2) ก๊อปปี้ไฟล์ `Demo_Setup.sh` ไปเป็นสคริปต์ติดตั้ง เช่น `my_tool/Setup_UI.sh`
3) แก้ไขข้อความภายใต้บล็อก `"$UI_BIN" - << 'EOF' ... EOF` ตามต้องการ:

   - `header = <ข้อความหัวเรื่องด้านบนสุด>`
   - `[page]` : สร้างหน้าตัวเลือก (มีกี่หน้าก็ได้ ต่อเนื่องกันได้)
       * `id = <ชื่ออ้างอิงหน้า>`
       * `title = <ชื่อขั้นตอน เช่น Step 1: Select Action>`
       * `var = <ชื่อตัวแปร Environment ที่จะรับค่าเมื่อผู้ใช้เลือก>`
       * `default = <ลำดับตัวเลือกเริ่มต้น เริ่มจาก 0>`
       * `option = <ค่าที่เก็บในตัวแปร> | <เป้าหมายถัดไป> | <ข้อความตัวเลือก> | <คำอธิบาย>`
         โดย `<เป้าหมายถัดไป>` เลือกใส่ได้ 4 แบบ:
           1. `next`          = ไปหน้า `[page]` ถัดไป
           2. `page:<id>`     = กระโดดไปหน้า `[page]` ที่มี `id` ตรงกัน
           3. `run:<id>`      = เริ่มรันหน้าหลอดติดตั้ง `[progress]` ที่มี `id` ตรงกัน
           4. `quit`          = ออกจากโปรแกรมทันที
   - `[progress]` : สร้างหน้าจอหลอด Progress Bar รันคำสั่งจริง
       * `id = <ชื่ออ้างอิงชุดคำสั่ง>`
       * `line1`, `line2`, `line3` = ข้อความอธิบายด้านบนกรอบ Progress
       * `box_title = <ข้อความหัวกรอบ Progress>`
       * `step = <เปอร์เซ็นต์ 0-100> | <ข้อความสถานะมุมขวาล่าง> | <คำสั่ง bash ที่ต้องการรัน>`
         (สามารถใช้ตัวแปร `$VAR` ที่ได้จากหน้า `[page]` ในคำสั่ง bash ได้โดยตรง)
       * `complete_title = <หัวข้อเมื่อติดตั้งเสร็จ>`
       * `complete_line = <ข้อความสรุปผลแต่ละบรรทัด (รองรับตัวแปร $VAR)>`

--------------------------------------------------------------------------------
5. วิธีคอมไพล์ซอร์สโค้ดใหม่บนเครื่อง R36H (กรณีแก้ไขไฟล์ setup_ui.c)
--------------------------------------------------------------------------------
หากมีการแก้ไขไฟล์ `setup_ui.c` สามารถคอมไพล์บนเครื่อง R36H ได้ด้วยคำสั่ง:

  gcc -O2 -Wall setup_ui.c -lSDL2 -o setup_ui
  chmod 755 setup_ui
