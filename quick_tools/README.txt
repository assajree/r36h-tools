================================================================================
R36H Quick Tools Shortcut (playOS)
================================================================================

[ OVERVIEW ]
แก้ปัญหาโฟลเดอร์ /roms/tools อยู่ลำดับท้ายๆ ทำให้ต้องเลื่อน (scroll) ผ่านโฟลเดอร์
เกมมากกว่า 50-80 โฟลเดอร์เพื่อเข้าถึง

เครื่องมือนี้จะสร้างทางลัดชื่อ "00_tools" ให้อยู่อันดับ 1 บนสุดของ /roms/ ทันที
ผ่านระบบ Bind Mount ถาวร (แก้ข้อจำกัดของพาร์ติชัน exFAT ที่ไม่รองรับคำสั่ง ln -s)
พร้อมตั้งค่าให้ทำงานอัตโนมัติทุกครั้งที่เปิดเครื่อง (/etc/fstab) และเพิ่มคำสั่งย่อ
"cdt" ใน Terminal

--------------------------------------------------------------------------------
[ FEATURES ]
--------------------------------------------------------------------------------
1. รันได้จากเมนู EmulationStation Tools (/roms/tools/) บนหน้าจอเครื่องโดยตรง
   (แสดงผลออก /dev/tty1 พร้อมระบบนับถอยหลัง 5 วินาทีก่อนกลับหน้าหลักอัตโนมัติ)
2. รองรับพาร์ติชัน exFAT ด้วย Bind Mount ถาวร
3. ตั้งค่าระบบบูตอัตโนมัติ (/etc/fstab)
4. เพิ่มคำสั่งย่อ 'cdt' ใน ~/.bashrc สำหรับเข้าผ่าน Terminal/SSH
5. ปลอดภัย ไม่ลบหรือแก้ไขไฟล์เกมใดๆ

--------------------------------------------------------------------------------
[ HOW TO USE ]
--------------------------------------------------------------------------------
วิธีที่ 1: ผ่านหน้าจอเครื่อง R36H
1. เข้าเมนู Tools ใน EmulationStation
2. เลือก "Create_Quick_Tools.sh"
3. สคริปต์จะตรวจสอบความพร้อม ตั้งค่า และนับถอยหลัง 5 วินาทีก่อนกลับหน้าเดิม
4. หลังจากนี้ เมื่อเปิดตัวจัดการไฟล์ (เช่น Web File Manager หรือ 351Files)
   จะเห็นโฟลเดอร์ "00_tools" อยู่อันดับแรกสุดทันที

วิธีที่ 2: รันผ่าน Terminal / SSH
   sudo bash /roms/tools/Create_Quick_Tools.sh

--------------------------------------------------------------------------------
[ HOW TO REMOVE ]
--------------------------------------------------------------------------------
หากต้องการยกเลิกทางลัด 00_tools:
1. สั่งยกเลิกเมานต์: sudo umount /roms/00_tools
2. ลบโฟลเดอร์เปล่า: rm -rf /roms/00_tools
3. ลบบรรทัด 00_tools ออกจาก /etc/fstab:
   sudo sed -i '/00_tools/d' /etc/fstab
