================================================================================
R36H Quick Tools Shortcut (playOS)
================================================================================

[ OVERVIEW ]
แก้ปัญหาโฟลเดอร์ /roms/tools อยู่ลำดับท้ายๆ ทำให้ต้องเลื่อน (scroll) ผ่านโฟลเดอร์
เกมมากกว่า 50-80 โฟลเดอร์เพื่อเข้าถึง

เครื่องมือนี้จะสร้างทางลัดชื่อ "00_tools" ให้อยู่อันดับ 1 บนสุดของ /roms/ ทันที
ผ่านระบบ Bind Mount ถาวร (แก้ข้อจำกัดของพาร์ติชัน exFAT ที่ไม่รองรับคำสั่ง ln -s)
พร้อมตั้งค่าให้ทำงานอัตโนมัติทุกครั้งที่เปิดเครื่อง (/etc/fstab) และเพิ่มคำสั่งย่อ
"cdt" ใน Terminal

โครงสร้างของเครื่องมือนี้ประกอบด้วย:
- Install_Quick_Tools.sh   : สคริปต์ติดตั้งและเปิดใช้งานทางลัด 00_tools ทันที
- Uninstall_Quick_Tools.sh : สคริปต์ถอดการติดตั้ง ยกเลิกเมานต์ และล้างค่าระบบทั้งหมด

--------------------------------------------------------------------------------
[ FEATURES ]
--------------------------------------------------------------------------------
1. รันครั้งเดียวเสร็จ (One-Shot): ไม่ทิ้ง service ทำงานค้างใน background ให้เปลือง RAM
2. Dual-Output: แสดงผลบนหน้าจอเครื่อง (/dev/tty1) และ Terminal/SSH พร้อมกัน
3. รองรับพาร์ติชัน exFAT ด้วย Bind Mount ถาวร
4. ตั้งค่าระบบบูตอัตโนมัติ (/etc/fstab) พร้อม timeout ป้องกันบูตช้า
5. เพิ่มคำสั่งย่อ 'cdt' ใน ~/.bashrc สำหรับเข้าถึงผ่าน Terminal / SSH
6. มีสคริปต์ Uninstall สำหรับถอดการติดตั้งและล้างค่ากลับคืนสภาพเดิมอย่างสมบูรณ์

--------------------------------------------------------------------------------
[ HOW TO INSTALL ]
--------------------------------------------------------------------------------
รันคำสั่งผ่าน Terminal หรือ SSH:
   sudo bash /roms/tools/quick_tools/Install_Quick_Tools.sh

หลังติดตั้งเสร็จ:
- เปิดตัวจัดการไฟล์ (เช่น Web File Manager หรือ 351Files) จะเห็นโฟลเดอร์ "00_tools"
  อยู่อันดับแรกสุดทันที
- ใน Terminal/SSH พิมพ์คำสั่ง 'cdt' เพื่อกระโดดไปยัง /roms/tools ได้ทันที

--------------------------------------------------------------------------------
[ HOW TO UNINSTALL ]
--------------------------------------------------------------------------------
หากต้องการยกเลิกและถอนการติดตั้ง:
   sudo bash /roms/tools/quick_tools/Uninstall_Quick_Tools.sh

สคริปต์จะทำการ:
1. ยกเลิก Bind Mount (/roms/00_tools)
2. ลบไดเรกทอรี /roms/00_tools
3. ลบบรรทัด 00_tools ออกจาก /etc/fstab
4. ลบคำสั่งย่อ 'cdt' ออกจาก ~/.bashrc
5. ล้างไฟล์รันเนอร์เก่าที่อาจตกค้างใน /roms/tools
