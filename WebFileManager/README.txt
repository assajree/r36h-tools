==============================================================================
  Web File Manager (Filebrowser) สำหรับ R36H (playOS 4.0 / dArkOS / ArkOS)
==============================================================================

[ ข้อมูลเบื้องต้น ]
เครื่องมือจัดการไฟล์แบบไร้สาย (Wireless Web File Manager) ผ่านโปรแกรม Filebrowser (ARM64)
ช่วยให้คุณสามารถเข้าถึงไฟล์เกม, เซฟ, รูปภาพ หรือไฟล์ระบบบนเครื่อง R36H ได้โดยตรงจาก
เว็บเบราว์เซอร์บนคอมพิวเตอร์, แท็บเล็ต หรือสมาร์ทโฟน โดยไม่ต้องถอด MicroSD Card ออกมา

[ จุดเด่นของเวอร์ชันใหม่ ]
1. ไฟล์เปิดเดี่ยวบนเมนู: มีเพียง "WebFileManager.sh" ตัวเดียวบนเมนู Ports ไม่รกสายตา
2. ควบคุมด้วย TUI (Text User Interface): รองรับปุ่ม Gamepad (D-Pad, A, B) เต็มรูปแบบ ผ่าน Native Console + gptokeyb
3. ติดตั้งเสร็จพร้อมใช้งานทันที (One-Shot Instant Start):
   - Config Auto-Start -> สรุปการตั้งค่า -> Install & Start Service ทันที
   - แสดงหน้าต่างสรุปสถานะพร้อมที่อยู่ IP และ URL
   - กด A หรือ Enter เพื่อออกสู่หน้ารวมเกมได้ทันที
4. ระบบ Virtual Storage Root อัตโนมัติ:
   - [Quick Link] Ports   : เข้าถึงโฟลเดอร์เกมพอร์ตทันที
   - [Quick Link] Tools   : เข้าถึงโฟลเดอร์เครื่องมือระบบ
   - [Storage] SD1 - Internal ROMs : เมมการ์ดหลัก
   - [Storage] SD2 - External ROMs : เมมการ์ดช่องที่ 2
5. ระบบ Auto-Start ตอนเปิดเครื่อง: เลือกเปิดหรือปิดการทำงานอัตโนมัติตอน Boot ได้จากในเมนู
6. จัดการ RAM ได้ทันใจ: มีตัวเลือก Stop Service เพื่อปิดการทำงานและคืน RAM ทั้งหมดก่อนเล่นเกม

[ การติดตั้งและใช้งาน ]
------------------------------------------------------------------------------
1. คัดลอกโฟลเดอร์ "WebFileManager" ทั้งหมดไปวางไว้ที่:
   - แนะนำ: /roms/ports/  (สำหรับ playOS 4.0, dArkOS, ArkOS)
   - หรือ:    /roms/tools/  (หากเปิดแท็บ Tools ไว้)

2. เข้าเมนู Ports (หรือ Tools) บนเครื่อง R36H แล้วเลือก "WebFileManager"

3. การควบคุมในหน้าต่าง TUI:
   - D-Pad ขึ้น / ลง : เลื่อนแถบเลือกเมนู
   - D-Pad ซ้าย / ขวา: สลับเลือกปุ่ม <OK>, <Cancel>, [ Install ], [ Back ]
   - ปุ่ม A หรือ START : ยืนยัน / เลือกคำสั่ง
   - ปุ่ม B             : ยกเลิก / ย้อนกลับ

------------------------------------------------------------------------------
[ เมนูคำสั่งภายใน WebFileManager ]
------------------------------------------------------------------------------
1. Start Service
   - เปิดระบบ Web File Manager แบบ On-Demand ทันที
   - พร้อมแสดงที่อยู่ IP และ URL สำหรับเปิดเข้าเว็บเบราว์เซอร์

2. Stop Service
   - ปิดระบบ Web File Manager และคืนหน่วยความจำ (RAM) ให้ระบบสำหรับเล่นเกม

3. Toggle Auto-Start
   - สลับเปิด/ปิดการเริ่มระบบอัตโนมัติตอนเปิดเครื่อง (Boot)
   - จัดการผ่าน systemd unit (filebrowser.service) อย่างเป็นระบบ

4. Uninstall
   - ลบ Service ในระบบ (filebrowser.service), ลบไบนารีใน /usr/local/bin และปิด Auto-Start
   - โดยยังคงไฟล์ WebFileManager.sh และรูปปกไว้ เพื่อให้เปิดกลับมาใช้งานหรือตั้งค่าใหม่ได้ทุกเมื่อ

5. Exit
   - ออกจากโปรแกรมกลับสู่หน้าเลือกเกม

------------------------------------------------------------------------------
[ การเข้าใช้งานจากคอมพิวเตอร์ หรือ มือถือ ]
------------------------------------------------------------------------------
1. เชื่อมต่อ Wi-Fi บนเครื่อง R36H ให้เรียบร้อย
2. เปิดเบราว์เซอร์ (Chrome, Safari, Edge ฯลฯ) บนอุปกรณ์ที่ต่อ Wi-Fi วงเดียวกัน
3. พิมพ์ URL:
   http://<IP-ของเครื่อง-R36H>
   หรือ
   http://playos.local

* ไม่ต้องใส่รหัสผ่าน (เข้าใช้งานได้ทันทีในโหมด noauth พอร์ต 80)
