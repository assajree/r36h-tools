==============================================================================
Screen Off / Screen Saver Utility for R36H (playOS)
==============================================================================

[ ข้อมูลทั่วไป ]
เครื่องมือสำหรับสั่ง "ดับไฟหน้าจอ (Backlight Off 100%)" ทันที เพื่อ:
1. ถนอมจอภาพและป้องกันความร้อนสะสมเมื่อเปิดเครื่องทิ้งไว้นานๆ
2. ประหยัดพลังงานแบตเตอรี่สูงสุด
3. ระบบหลัก (CPU / Wi-Fi / SSH / Web File Manager / งานดาวน์โหลดไฟล์) ยังคงทำงานต่อเนื่อง 100% 
   ไม่ถูก Suspend/Sleep เหมือนการกดสลีปปกติ จึงทำให้การดาวน์โหลดและโอนไฟล์ไม่หลุด

------------------------------------------------------------------------------
[ วิธีติดตั้ง ]
------------------------------------------------------------------------------
วิธีที่ 1: ติดตั้งผ่าน Terminal / SSH
รันคำสั่ง:
  sudo bash /roms/tools/screen_off/Install_Screen_Off.sh

วิธีที่ 2: ติดตั้งผ่าน EmulationStation
คัดลอกไฟล์ Screen_Off.sh ไปไว้ที่โฟลเดอร์ /roms/tools/

------------------------------------------------------------------------------
[ วิธีใช้งาน ]
------------------------------------------------------------------------------
1. บนหน้าจอเครื่อง R36H (EmulationStation):
   - เข้าเมนู Tools
   - เลือก "Screen_Off.sh"
   - หน้าจอจะดับสนิททันที

2. บน Terminal / SSH:
   - พิมพ์คำสั่ง: screen_off
   - หรือพิมพ์: sudo bash /roms/tools/Screen_Off.sh

------------------------------------------------------------------------------
[ วิธีปลุกหน้าจอให้สว่างกลับมา ]
------------------------------------------------------------------------------
กดปุ่มใดก็ได้บนตัวเครื่อง 1 ครั้ง เช่น:
- D-Pad (ขึ้น / ลง / ซ้าย / ขวา)
- ปุ่ม A / B / X / Y
- ปุ่ม L1 / R1 / Start / Select
หน้าจอจะสว่างขึ้นสู่ระดับความสว่างเดิมทันที และกลับเข้าสู่ EmulationStation อย่างราบรื่น
