==============================================================================
   คู่มือการใช้งาน Web File Manager (Filebrowser) สำหรับ R36H (playOS)
==============================================================================

เครื่องมือนี้ช่วยให้คุณสามารถจัดการไฟล์ (อัปโหลด ROMs, ดาวน์โหลดเซฟเกม, จัดการโฟลเดอร์)
บนเครื่อง R36H ได้อย่างง่ายดายผ่านเว็บเบราว์เซอร์จากคอมพิวเตอร์หรือมือถือ
โดยไม่ต้องถอดการ์ด MicroSD และไม่ต้องต่อสาย USB!

------------------------------------------------------------------------------
โครงสร้างไฟล์ในแพ็กเกจ:
------------------------------------------------------------------------------
web_filemanager/
  ├── filebrowser                  <-- โปรแกรม Web File Manager (Linux ARM64)
  ├── Install_Web_FileManager.sh   <-- สคริปต์ติดตั้งระบบลงเครื่อง R36H
  ├── Start_Web_FileManager.sh     <-- เมนูเปิดระบบจัดการไฟล์ผ่านเว็บ
  ├── Stop_Web_FileManager.sh      <-- เมนูปิดระบบเพื่อคืน RAM
  └── README.txt                   <-- ไฟล์คู่มือนี้

------------------------------------------------------------------------------
วิธีติดตั้ง (ทำครั้งแรกเพียงครั้งเดียว):
------------------------------------------------------------------------------
1. นำโฟลเดอร์ `web_filemanager` ไปวางไว้ใน MicroSD Card ที่โฟลเดอร์:
   /roms/tools/web_filemanager/

2. รันสคริปต์ติดตั้ง:
   - ผ่าน SSH บนคอมพิวเตอร์:
       sudo bash /roms/tools/web_filemanager/Install_Web_FileManager.sh
   - หรือผ่านเมนู Tools/Options ในเครื่อง R36H

3. เมื่อติดตั้งเสร็จ จะมี 2 เมนูเพิ่มขึ้นมาใน Tools:
   - "Start Web File Manager"
   - "Stop Web File Manager"

------------------------------------------------------------------------------
วิธีเปิดใช้งาน:
------------------------------------------------------------------------------
1. ต่อ Wi-Fi บนเครื่อง R36H ให้เรียบร้อย
2. ไปที่เมนู Tools / Options บนเครื่อง R36H แล้วเลือก:
   --> "Start Web File Manager"
3. หน้าจอเครื่องจะแสดง IP Address สำหรับเปิดเว็บ เช่น:
   http://192.168.1.150:8080
4. เปิดคอมพิวเตอร์หรือมือถือที่ต่อ Wi-Fi วงเดียวกัน แล้วเปิดเว็บเบราว์เซอร์พิมพ์ตามที่ระบุ
5. หน้าต่าง File Manager จะเปิดขึ้นมาทันที:
   - ลากไฟล์ ROMs เข้ามาใส่ในโฟลเดอร์เกมที่ต้องการได้เลย
   - สามารถสร้างโฟลเดอร์, เปลี่ยนชื่อ, แตกไฟล์ zip ได้ในตัว
   - แก้ไขไฟล์สคริปต์/config ได้ทันที
6. เมื่อจัดการไฟล์เสร็จแล้ว บนเครื่อง R36H ให้เลือก:
   --> "Stop Web File Manager" เพื่อปิดระบบและคืน RAM ทั้งหมดให้เกมเล่นได้ลื่นไหล
