================================================================================
Web Terminal (ttyd ARM64) สำหรับเครื่องเล่นเกม R36H (playOS / ArkOS)
================================================================================

[ ความสามารถเด่น ]
- เปิด Terminal ควบคุมเครื่อง R36H ผ่านเว็บเบราว์เซอร์บนมือถือหรือคอมพิวเตอร์
- แก้ปัญหาคีย์บอร์ดบนหน้าจอ R36H กดยาก หรือไม่มีปุ่มพิเศษ เช่น Pipe (|)
- สามารถ Copy / Paste คำสั่งยาวๆ จากคอมพิวเตอร์หรือมือถือลงไปได้โดยตรง
- ใช้โปรแกรม ttyd (C-based) ตัวจิ๋ว กิน RAM เพียง ~5MB ไม่หน่วงเครื่อง
- สิทธิ์ Root Shell สมบูรณ์ พร้อมเริ่มทำงานที่โฟลเดอร์ /roms ทันที
- 100% Offline ไม่ต้องต่อเน็ตเพื่อติดตั้ง

--------------------------------------------------------------------------------
[ โครงสร้างโฟลเดอร์ ]
--------------------------------------------------------------------------------
web_terminal/
├── Install_Web_Terminal.sh    <-- ไฟล์ติดตั้งหลัก (รันเพื่อสร้างเมนู Start/Stop ใน Tools)
├── Uninstall_Web_Terminal.sh  <-- ไฟล์ถอนการติดตั้ง (ลบ service, binary และ shortcuts)
├── README.txt                 <-- คู่มือการใช้งานนี้
└── app/                       <-- โฟลเดอร์เก็บระบบภายใน
    ├── ttyd                   <-- โปรแกรม Web Terminal ARM64
    ├── Start_Web_Terminal.sh  <-- สคริปต์เริ่มการทำงาน
    └── Stop_Web_Terminal.sh   <-- สคริปต์หยุดการทำงานเพื่อคืน RAM

--------------------------------------------------------------------------------
[ วิธีติดตั้งครั้งแรก ]
--------------------------------------------------------------------------------
1. ก๊อปปี้โฟลเดอร์ 'web_terminal' ไปวางไว้ในการ์ดความจำ (SD Card) ช่อง ROMs
   ปลายทางจะเป็น: /roms/tools/web_terminal/
2. เปิดเครื่อง R36H เข้าเมนู Tools หรือ Terminal แล้วพิมพ์คำสั่ง:
   sudo bash /roms/tools/web_terminal/Install_Web_Terminal.sh
3. ระบบจะคัดลอกไฟล์โปรแกรมและสร้างเมนู 'Start Web Terminal' และ 'Stop Web Terminal'
   ไว้ที่เมนู Tools ให้อัตโนมัติ

--------------------------------------------------------------------------------
[ วิธีใช้งาน ]
--------------------------------------------------------------------------------
1. เชื่อมต่อเครื่อง R36H กับสัญญาณ Wi-Fi เดียวกันกับมือถือหรือคอมพิวเตอร์
2. บนเครื่อง R36H: เข้าเมนู Tools -> เลือก "Start Web Terminal"
3. หน้าจอเครื่องจะแสดงหมายเลข IP และลิงก์ เช่น:
   --> http://192.168.1.150:7681
4. เปิดเบราว์เซอร์ (Chrome, Safari, Edge) บนมือถือหรือคอม แล้วพิมพ์ URL ดังกล่าว
5. คุณจะพบหน้าต่าง Console Terminal สีดำ สามารถพิมพ์คำสั่ง รันสคริปต์ ซ่อมระบบ 
   หรือแก้ไขไฟล์ได้ทันทีด้วยคีย์บอร์ดจริง
6. เมื่อใช้งานเสร็จสิ้น: บนเครื่อง R36H ให้เข้าเมนู Tools -> เลือก "Stop Web Terminal"
   เพื่อปิดบริการและคืน RAM ทั้งหมดให้ระบบพร้อมสำหรับการเล่นเกมอย่างลื่นไหล

--------------------------------------------------------------------------------
[ วิธีถอนการติดตั้ง ]
--------------------------------------------------------------------------------
หากต้องการลบโปรแกรมและเมนู Start/Stop ออกจากระบบ:
รันคำสั่งใน Terminal:
sudo bash /roms/tools/web_terminal/Uninstall_Web_Terminal.sh
