================================================================================
R36H playOS Tools Menu Enabler (tools_menu)
================================================================================

[ OVERVIEW ]
สคริปต์สำหรับเปิดใช้งานหมวดหมู่ "TOOLS" บนแถบเมนูหลักของ playOS 4.0 (playfe)
เพื่อให้สามารถกดรันเครื่องมือ (.sh) ในโฟลเดอร์ /roms/tools/ พร้อมแสดงรูปปกจาก
/roms/tools/images/<ชื่อไฟล์>-thumb.png ได้โดยตรงจากหน้าจอเครื่อง R36H

โครงสร้างของเครื่องมือนี้ (Archetype 4 - System Configuration):
- Install_Tools_Menu.sh   : เปิดใช้งานหมวดหมู่ TOOLS ใน es_systems.cfg และรีเฟรชเมนู
- Uninstall_Tools_Menu.sh : ปิดการแสดงผลหมวดหมู่ TOOLS ออกจาก es_systems.cfg

--------------------------------------------------------------------------------
[ HOW IT WORKS ]
--------------------------------------------------------------------------------
1. เพิ่มบล็อก <system> สำหรับ <name>tools</name> ลงในไฟล์
   /etc/emulationstation/es_systems.cfg โดยใช้ไอคอนและธีม "tools" ที่ติดมากับ
   playOS (/usr/local/share/playfe/logos/tools.png)
2. เตรียมโฟลเดอร์ /roms/tools/ และ /roms/tools/images/ สำหรับวางสคริปต์และรูปปก
3. สั่งรีสตาร์ทเซอร์วิส playfe.service เพื่อให้เมนู TOOLS ปรากฏขึ้นทันทีโดยไม่ต้องรีบูต
4. ไม่แก้ไขหรือพึ่งพาไฟล์ gamelist.xml (ตัว playfe จะดึงชื่อแอปจากชื่อไฟล์ .sh และดึง
   รูปปกจาก /roms/tools/images/<ชื่อสคริปต์>-thumb.png มาแสดงให้อัตโนมัติ)

--------------------------------------------------------------------------------
[ HOW TO INSTALL / ENABLE ]
--------------------------------------------------------------------------------
รันคำสั่งผ่าน Terminal หรือ SSH:
   sudo bash /roms/tools/tools_menu/Install_Tools_Menu.sh

--------------------------------------------------------------------------------
[ HOW TO UNINSTALL / DISABLE ]
--------------------------------------------------------------------------------
หากต้องการซ่อนหมวดหมู่ TOOLS ออกจากหน้าเมนูหลัก:
   sudo bash /roms/tools/tools_menu/Uninstall_Tools_Menu.sh
